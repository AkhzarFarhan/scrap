1. Protocol Architecture & Functional Splits L2 Baseband

Radio Protocol Stack (User Plane):

  • SDAP (TS 37.324): QoS Flow $\leftrightarrow$ Data Radio Bearer (DRB) mapping; reflective QoS marking.
  • PDCP (TS 38.323): Sequence numbering, ciphering (AES/SNOW3G), integrity, ROHC header compression, in-order delivery, re-ordering, split-bearer duplicate discard.
  • RLC (TS 38.322): TM (Transparent), UM (Unacknowledged), AM (Acknowledged). ARQ retransmission, segmentation (no re-segmentation in MAC), SDU discard timer.
  • MAC (TS 38.321): Logical channel prioritization (LCP), HARQ with CBG, dynamic/configured multiplexing, random access (RACH), timing advance (TA), BWP switching, DRX, beam failure recovery, Carrier Aggregation (CA).
O-RAN & 3GPP Split Options:
• Option 2 (3GPP Rel-15): High-layer split: CU (PDCP/SDAP/RRC) $\leftrightarrow$ F1 interface $\leftrightarrow$ DU (RLC/MAC/High-PHY).
• Option 7.2x (O-RAN WG4): Lower-layer split: DU (MAC + High-PHY FFT/iFFT/Scrambling/Modulation) $\leftrightarrow$ Fronthaul eCPRI $\leftrightarrow$ RU (Low-PHY Beamforming + RF).
• Small Cell Forum FAPI P7: Slot-by-slot MAC $\leftrightarrow$ PHY real-time interface (DL_TTI.request, UL_TTI.request, TX_Data.request, RX_Data.indication).

3. Frame & Slot Time-Domain Geometry TS 38.211
  • Radio Frame: $T_f = 10\text{ ms} = \frac{\Delta f_{\max} \cdot N_f}{100} \cdot T_c = 10\text{ subframes}$. Constant across all numerologies.
  • Subframe: $T_{\text{sf}} = 1.0\text{ ms}$. Exact unit of time across all numerologies.
  • Slot Duration: $T_{\text{slot}} = \frac{1}{2^\mu}\text{ ms}$. Contains exactly 14 OFDM symbols for Normal CP (12 for Extended CP, $\mu=2$ only).
  • Mini-Slot (Non-slot based): 2, 4, or 7 symbols. Enables sub-1ms ultra-low latency URLLC transmission and pre-emption of scheduled eMBB traffic.

5. Bandwidth Parts (BWP) Operation TS 38.213 §12
  • Definition: Contiguous subset of PRBs sharing a single numerology ($\mu$) on a given component carrier. Max 4 BWPs configured in DL and UL; exactly 1 active BWP at any instant.
  • Initial BWP: Used for Initial Access, SIB1 decoding (RMSI), and RACH prior to dedicated RRC. Derived from CORESET#0 / Type0-PDCCH.
  • Active BWP: Dedicated UE operational BWP for high-throughput data transfer.
  • Default BWP: Fallback BWP when bwp-InactivityTimer expires. Prevents high battery drain on wideband (100MHz) when traffic is idle.
  • Dormant BWP: Rel-16 SCell state where UE stops PDCCH monitoring but continues CQI/CSI measurements and AGC, enabling sub-millisecond reactivation.
  • Switching Mechanisms: DCI format 1_1/0_1 (BWP indicator field, 1-2 bits), bwp-InactivityTimer timeout, RRC reconfiguration, or RACH initiation.
6. Resource Allocation: SLIV & Frequency Domain TS 38.214 §5.1.2

Time Domain (SLIV - Start and Length Indicator Value):

$\text{If } (L - 1) \le 7 \implies \mathbf{\text{SLIV} = 14 \cdot (L - 1) + S}$
$\text{Else } \implies \mathbf{\text{SLIV} = 14 \cdot (14 - L + 1) + (14 - 1 - S)}$

Where $S \in [0..13]$ is start symbol and $L \in [1..14]$ is contiguous symbol length ($S + L \le 14$). Single 7-bit field encodes all 105 valid combinations.

Frequency Domain Allocation:

  • Type 0 (Bitmap): RBG bitmap allocation. RBG size $P \in \{2, 4, 8, 16\}$ PRBs based on BWP size Configuration 1 or 2. Flexible frequency selectivity for Proportional Fair.
  • Type 1 (RIV - Resource Indication Value): Contiguous PRB allocation encoded as compact integer: $$\text{If } (L_{\text{RBs}} - 1) \le \lfloor N_{\text{BWP}}^{\text{size}}/2 \rfloor \implies \text{RIV} = N_{\text{BWP}}^{\text{size}}(L_{\text{RBs}} - 1) + \text{RB}_{\text{start}}$$ $$\text{Else } \implies \text{RIV} = N_{\text{BWP}}^{\text{size}}(N_{\text{BWP}}^{\text{size}} - L_{\text{RBs}} + 1) + (N_{\text{BWP}}^{\text{size}} - 1 - \text{RB}_{\text{start}})$$

2. Downlink HARQ Protocol Mechanics TS 38.213 / 38.321
  • Asynchronous Dynamic Timing ($K_1$): Downlink HARQ is fully asynchronous. The slot offset $K_1$ between PDSCH reception and PUCCH HARQ-ACK transmission is dynamically signalled in DCI (0 to 15 slots).
  • HARQ Processes: Up to 16 parallel Stop-and-Wait processes per carrier per UE. Process ID indicated in DCI (4 bits).
  • New Data Indicator (NDI): Toggled bit indicates a new transmission; non-toggled indicates a retransmission of the active HARQ buffer.
  • Redundancy Versions (RV): LDPC circular buffer rate matching.
    $\text{Standard Retransmission Sequence: } \mathbf{RV_0 \longrightarrow RV_2 \longrightarrow RV_3 \longrightarrow RV_1}$
    • $RV_0$: Full systematic bits (highest decoding probability if SNR is good).
    • $RV_2$: Parity-heavy incremental redundancy (lowest code rate when combined).
    • $RV_3, RV_1$: Remaining parity bits for Chase Combining or IR.
3. Code Block Group (CBG) Retransmission TS 38.212 / 38.214
  • Transport Block Segmentation: If TB size $> 3824$ bits (Base Graph 1) or $> 292$ bits, TB is segmented into Code Blocks (max $K_{cb} = 8448$ bits for BG1, $3840$ bits for BG2).
  • CBG Grouping: RRC configures maxCodeBlockGroupsPerTransportBlock $\in \{2, 4, 6, 8\}$. CBs mapped uniformly into $N_{\text{CBG}}$ groups.
  • CBGTI (Transmission Information): DCI bitmask where bit $k=1$ indicates CBG $k$ is retransmitted. Corrupt CBGs retransmitted individually rather than whole 100+ kB TB.
  • CBGFI (Flush Indicator): Bit indicating whether previously corrupted CBGs in UE soft buffer should be flushed or combined.
Baseband Efficiency Gain: In bursty interference or high Doppler channels, CBG retransmissions reduce retransmission radio overhead by 75%–80%, preserving spectral efficiency.

5. Link Adaptation & OLLA Convergence Closed-Form Math
  • CQI Reporting: 4-bit CQI index (Tables 1–3: QPSK up to 256-QAM) reporting highest MCS supporting $\le 10\%$ BLER.
  • Effective SNR Formulation: $$\text{SNR}_{\text{effective}} = \text{SNR}_{\text{reported}}(\text{CQI}) + \Delta_{\text{OLLA}} - \text{Margin}_{\text{safety}}$$
  • OLLA Step-Size Balance Equation:
    $\mathbf{\Delta_{\text{down}} = \Delta_{\text{up}} \times \frac{\text{BLER}_{\text{target}}}{1 - \text{BLER}_{\text{target}}}} \iff \mathbf{\Delta_{\text{up}} = \Delta_{\text{down}} \times \frac{1 - \text{BLER}_{\text{target}}}{\text{BLER}_{\text{target}}}}$
  • Target 10% BLER ($\text{BLER} = 0.10$): $$\Delta_{\text{down}} = \Delta_{\text{up}} \times \frac{0.10}{0.90} = \frac{\Delta_{\text{up}}}{9} \implies \mathbf{\Delta_{\text{up}} = 9 \times \Delta_{\text{down}}}$$ If $\Delta_{\text{down}} = 0.1\text{ dB (on ACK)} \implies \Delta_{\text{up}} = 0.9\text{ dB (on NACK)}$. Exactly 9 consecutive ACKs are required to recover from a single NACK.

1. Carrier Aggregation (CA) Architecture TS 38.300 §5.5
  • Cell Hierarchy: Primary Cell (PCell) controls RRC, security, NAS, and primary PUCCH. Secondary Cells (SCell, up to 15 CCs) add capacity. SpCell = PCell (MCG) or PSCell (SCG).
  • Deployment Modes: Intra-band contiguous (adjacent spectrum in same band), Intra-band non-contiguous, Inter-band (e.g. n78 3.5 GHz TDD + n28 700 MHz FDD).
  • Cross-Carrier Scheduling: PDCCH on scheduling cell allocates PDSCH/PUSCH on scheduled cell via 3-bit Carrier Indicator Field (CIF).
  • Cross-Numerology Slot Mapping:
    $n_{\text{scheduled}} = \lfloor n_{\text{scheduling}} \cdot 2^{\mu_{\text{scheduled}} - \mu_{\text{scheduling}}} \rfloor + K_0$
2. SCell Activation / Deactivation Lifecycle TS 38.321 §5.9 / TS 38.133
  • RRC Configuration: Adds SCell to UE configuration in deactivated state.
  • MAC CE Activation: 1-Octet ($LCID = 58$) for SCells 1–7, or 4-Octet ($LCID = 57$) for SCells 1–31. Bitmap field $C_i=1$ activates SCell ID $i$.
  • Deactivation Timer (sCellDeactivationTimer): Configured per SCell ($20\text{ ms} \dots 1280\text{ ms}$). Reset upon any PDSCH scheduling grant on that SCell. Expiry automatically deactivates SCell to save UE battery.
  • Activation Latency Budgets (TS 38.133 §8.3):
    • Known / Warm SCell: $T_{\text{activate}} \le 24\text{ ms}$ (recent CSI/fine timing valid).
    • Unknown / Cold SCell: $T_{\text{activate}} \le 34\text{ ms}$ (requires SSB beam search, AGC acquisition, timing sync before valid CSI reporting).
3. ML SCell Prediction via Treelite Compilation Sub-15 µs Inference
  • The Problem: Python/XGBoost inference runtime ($>1.2\text{ ms}$) violates the 125 µs L2 MAC scheduling slot deadline and risks buffer overflow.
  • Feature Vector ($X \in \mathbb{R}^{12}$): Instantaneous RSRP, RSRQ, Doppler spread, CQI variance, RLC buffer depth, packet arrival rate, historical SINR.

float predict_scell_activation(const float* f) {

5. 4-Step HARQ NACK Storm Root-Cause Triage SOP Execution
  • Step 1: Check DCI Grant Detection (PDCCH CCEs):
    • Symptom: Baseband detects DTX on PUCCH (UE sends nothing).
    • Root Cause: UE missed DCI grant due to low PDCCH Aggregation Level (AL 1/2 instead of AL 8/16) or beam misalignment in SSB/CSI-RS sweep.
  • Step 2: Check Link Adaptation & OLLA Convergence:
    • Symptom: Immediate NACK on $RV_0$; CRC failure across all PRBs.
    • Root Cause: Assigned MCS exceeds instant channel capacity. OLLA step $\Delta_{\text{up}}$ not aggressive enough, or CQI report delayed by $>20\text{ ms}$ during fast fading.
  • Step 3: Check PDSCH Demodulation & Co-Channel Interference:
    • Symptom: EVM degrades significantly on data REs while DMRS correlation remains intact.
    • Root Cause: Adjacent-cell co-channel interference on specific RBGs; Doppler-induced inter-carrier interference (ICI) at high speed ($>120\text{ km/h}$).
  • Step 4: Check Timing Advance (TA) Drift & PUCCH Sync:
    • Symptom: gNodeB decodes valid PDSCH CRC at UE side, but gNodeB logs NACK/DTX on PUCCH.
    • Root Cause: TA expired (timeAlignmentTimer), UE uplink symbol overlap causing FFT window clipping, or UL pathloss estimation error.

5. The 10 Golden Rules of 5G Baseband Development Systems Commandments
  • 1. Zero Dynamic Allocation: Never call malloc, new, or resize STL containers inside the 125 µs slot hot-path.
  • 2. Cache-Line Alignment: Align all PCIe DMA buffers and descriptor rings to 64-byte boundaries (alignas(64)).
  • 3. Lock-Free Coordination: Never hold an OS mutex across MAC multiplexing; use atomic lock-free SPSC queues for cross-core IPC.
  • 4. Bounded LCP Tokens: Always cap logical channel token buckets by Bucket Size Duration (BSD) to prevent burst starvation.
  • 5. Guard DAI Overflow: Handle modulo-4 Counter DAI wrap-around and out-of-order DCI arrivals in Type-2 codebooks.
  • 6. CBG Granularity: Enable CBG-based retransmission for transport blocks $> 20\text{ kB}$ to minimize air-interface retransmission tax.
  • 7. OLLA Step Asymmetry: Maintain strict step balance ($\Delta_{\text{up}} = 9 \cdot \Delta_{\text{down}}$ for 10% BLER); never make steps symmetric.
  • 8. Isolate SCell RRC from MAC: Keep asynchronous RRC configuration off the synchronous MAC CE activation path.
  • 9. Zero QXDM Log Drops: Design log ring buffers with backpressure to guarantee zero dropped packets during telemetry triage.
  • 10. Cross-Carrier Numerology Check: Always verify slot alignment formulas when aggregating carriers with differing SCS ($\mu_1 \neq \mu_2$).
