1. Protocol Architecture & Functional Splits L2 Baseband

Radio Protocol Stack (User Plane):

  • SDAP (TS 37.324): Maps 5G QoS Flows (5QI) to Data Radio Bearers (DRBs); reflective QoS marking in DL.
  • PDCP (TS 38.323): Sequence numbering, ciphering/integrity (AES/SNOW3G), ROHC header compression, reordering, duplicate discard in dual connectivity.
  • RLC (TS 38.322): TM (Transparent), UM (Unacknowledged), AM (Acknowledged). ARQ retransmission, segmentation to fit MAC grant size, SDU discard timer.
  • MAC (TS 38.321): Logical Channel Prioritization (LCP), HARQ with CBG, dynamic scheduling, RACH, Timing Advance (TA), BWP switching, DRX, Carrier Aggregation (CA).
O-RAN & FAPI Splits:
• Option 2 (3GPP Rel-15): CU (PDCP/SDAP/RRC) $\leftrightarrow$ F1 interface $\leftrightarrow$ DU (RLC/MAC/High-PHY).
• Option 7.2x (O-RAN): DU (MAC + High-PHY) $\leftrightarrow$ Fronthaul eCPRI $\leftrightarrow$ RU (Low-PHY Beamforming/RF).
• SCF FAPI P7: Slot-by-slot MAC $\leftrightarrow$ PHY real-time interface (DL_TTI.req, UL_TTI.req, TX_Data.req).

4. Frame & Slot Time-Domain Geometry TS 38.211
  • Radio Frame: $T_f = 10\text{ ms} = 10\text{ subframes}$. Constant across all numerologies.
  • Subframe: $T_{\text{sf}} = 1.0\text{ ms}$. Exact universal timing anchor across all numerologies.
  • Slot Duration: $T_{\text{slot}} = 1/2^\mu\text{ ms}$. Exactly 14 OFDM symbols for Normal CP (12 for Extended CP, $\mu=2$ only).
  • Mini-Slot (Non-slot based): 2, 4, or 7 symbols. Enables sub-1ms ultra-low latency URLLC transmission and pre-emption of scheduled eMBB traffic.
5. Bandwidth Parts (BWP) Operation TS 38.213 §12
  • Definition: Contiguous subset of PRBs sharing single numerology ($\mu$) on a carrier. Max 4 BWPs configured in DL and UL; exactly 1 active BWP at any instant.
  • Initial BWP: Used for Initial Access, SIB1 decoding (RMSI), and RACH prior to dedicated RRC. Derived from CORESET#0 / Type0-PDCCH.
  • Active BWP: Dedicated UE operational BWP for high-throughput data transfer.
  • Default BWP: Fallback BWP when bwp-InactivityTimer expires. Reduces power consumption by narrowing bandwidth during idle periods.
  • Dormant BWP: Rel-16 SCell state: UE stops PDCCH monitoring but continues CQI/CSI measurements and AGC, enabling sub-millisecond reactivation.
  • Switching: DCI format 1_1/0_1 (BWP indicator field), bwp-InactivityTimer timeout, RRC reconfiguration, or RACH initiation.
6. Resource Allocation: SLIV & Frequency Domain TS 38.214 §5.1.2

Time Domain (SLIV - Start and Length Indicator Value):

$\text{If } (L - 1) \le 7 \implies \mathbf{\text{SLIV} = 14 \cdot (L - 1) + S}$
$\text{Else } \implies \mathbf{\text{SLIV} = 14 \cdot (14 - L + 1) + (14 - 1 - S)}$

Where $S \in [0..13]$ is start symbol and $L \in [1..14]$ is contiguous symbol length ($S + L \le 14$). Reverse decoding: $L = \lfloor \text{SLIV}/14 \rfloor + 1$, $S = \text{SLIV} \bmod 14$. If $(S+L) > 14 \implies L = 14 - L + 2$, $S = 13 - S$.

Frequency Domain Allocation:

  • Type 0 (Bitmap): RBG bitmap allocation. RBG size $P \in \{2, 4, 8, 16\}$ PRBs based on BWP size Configuration 1 or 2. Flexible frequency selectivity for Proportional Fair.
  • Type 1 (RIV - Resource Indication Value): Contiguous PRB allocation encoded as single integer: $$\text{If } (L_{\text{RBs}} - 1) \le \lfloor N_{\text{BWP}}^{\text{size}}/2 \rfloor \implies \text{RIV} = N_{\text{BWP}}^{\text{size}}(L_{\text{RBs}} - 1) + \text{RB}_{\text{start}}$$ $$\text{Else } \implies \text{RIV} = N_{\text{BWP}}^{\text{size}}(N_{\text{BWP}}^{\text{size}} - L_{\text{RBs}} + 1) + (N_{\text{BWP}}^{\text{size}} - 1 - \text{RB}_{\text{start}})$$

2. Downlink HARQ Protocol Mechanics TS 38.213 / 38.321
  • Asynchronous Dynamic Timing ($K_1$): Downlink HARQ is fully asynchronous. Slot offset $K_1$ between PDSCH reception and PUCCH HARQ-ACK transmission is dynamically signalled in DCI (0 to 15 slots).
  • HARQ Processes: Up to 16 parallel Stop-and-Wait processes per carrier per UE. Process ID indicated in DCI (4 bits).
  • New Data Indicator (NDI): Toggled bit indicates a new transmission; non-toggled indicates a retransmission of active HARQ buffer.
  • Redundancy Versions (RV): LDPC circular buffer rate matching.
    $\text{Standard Retransmission Sequence: } \mathbf{RV_0 \longrightarrow RV_2 \longrightarrow RV_3 \longrightarrow RV_1}$
    • $RV_0$: Full systematic bits (highest decoding probability if SNR is good).
    • $RV_2$: Parity-heavy incremental redundancy (lowest code rate when combined).
    • $RV_3, RV_1$: Remaining parity bits for Chase Combining or IR.
  • Code Block Group (CBG) Retransmission: If TB size $> 3824$ bits (BG1), TB is segmented into CBs ($K_{cb}=8448$ bits) and grouped into $N_{\text{CBG}} \in \{2, 4, 6, 8\}$ CBGs. CBGTI bitmask in DCI retransmits corrupt CBGs only $\implies$ 75%–80% radio overhead reduction.
  • HARQ-ACK Codebooks: Type-1 (Semi-static fixed bit length based on candidate TDRA $\times K_1$ set) vs Type-2 (Dynamic payload driven by Counter DAI & Total DAI fields in DCI, detecting missed grants).
3. Link Adaptation & OLLA Convergence Closed-Form Math
  • Effective SNR Formulation: $\text{SNR}_{\text{effective}} = \text{SNR}_{\text{reported}}(\text{CQI}) + \Delta_{\text{OLLA}} - \text{Margin}_{\text{safety}}$.
  • OLLA Step-Size Balance Equation:
    $\mathbf{\Delta_{\text{down}} = \Delta_{\text{up}} \times \frac{\text{BLER}_{\text{target}}}{1 - \text{BLER}_{\text{target}}}} \iff \mathbf{\Delta_{\text{up}} = \Delta_{\text{down}} \times \frac{1 - \text{BLER}_{\text{target}}}{\text{BLER}_{\text{target}}}}$
  • Target 10% BLER ($\text{BLER} = 0.10$): $$\Delta_{\text{down}} = \Delta_{\text{up}} \times \frac{0.10}{0.90} = \frac{\Delta_{\text{up}}}{9} \implies \mathbf{\Delta_{\text{up}} = 9 \times \Delta_{\text{down}}}$$ If $\Delta_{\text{down}} = 0.1\text{ dB (on ACK)} \implies \Delta_{\text{up}} = 0.9\text{ dB (on NACK)}$. Exactly 9 consecutive ACKs are required to recover from a single NACK.
